# Student Portfolios

Student portfolios should document learning progress and evidence, not merely final products.

## Suggested evidence structure

1. Context and task
2. Evidence/product
3. Reflection on decisions
4. Feedback received
5. Revision or improvement
6. Link to relevant learning outcome

## Privacy

Do not publish personal, health, assessment, or other sensitive student information in this public hub. Portfolio repositories should use access settings appropriate to the course and evidence type.
