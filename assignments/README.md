# Assignments

This directory defines shared assignment conventions for RU-HEPE Learning Hub.

## Standard assignment package

Each assignment should state:

- learning outcomes addressed
- task and deliverables
- permitted evidence/data sources
- submission method and deadline
- assessment rubric
- academic integrity and AI-use expectations
- privacy requirements

## Submission principle

Do not place identifiable student work or sensitive information in this public repository. Public assignment specifications may live here; student submissions should be stored in appropriately controlled repositories.
