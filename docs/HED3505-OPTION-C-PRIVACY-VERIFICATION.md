# HED3505 Option C — Privacy Verification Checklist

Before real-student start verify:

- [ ] Public GitHub contains no student-specific records.
- [ ] Interactive Lab requests no student ID.
- [ ] Interactive Lab requests no health information.
- [ ] Official grades are outside public GitHub.
- [ ] Exact private submission destination is confirmed.
- [ ] Student access is limited to appropriate private space.
- [ ] Instructor access is confirmed.
- [ ] Feedback remains private.
- [ ] Revision evidence remains private.
- [ ] Portfolio evidence remains private.
- [ ] Public troubleshooting will not include student work.
- [ ] Rollback/removal process is known.

## Decision rule

Any unresolved privacy-control item keeps REAL-STUDENT START on HOLD.
