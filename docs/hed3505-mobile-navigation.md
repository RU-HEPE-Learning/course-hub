## Mobile design rules

- Keep the main route within 1–2 taps from the HED3505 entry page.
- Prefer Markdown and simple static pages.
- Do not require command-line Git.
- Do not require GitHub Classroom.
- Avoid unnecessary forms or duplicate data entry.
- Student work remains private by default.
