# RU-HEPE Learning Hub — Classroom Replacement Architecture

## Purpose
This repository is the central hub for course discovery, assignment distribution, assessment guidance, and student portfolio navigation across RU-HEPE-Learning.

## Repository model
- `course-hub` — central navigation and governance hub
- `assignment-template` — reusable starter structure for assignments
- `student-portfolio-template` — reusable student e-portfolio starter
- `course-HED3505` — pilot course workspace for HED3505

## Operating principles
1. Evidence-First / No Fabrication
2. Minimum student friction
3. Clear separation between public learning materials and private assessment records
4. Pull-request based submission and feedback where appropriate
5. Reusable templates across courses
6. Human authority retained for grading and final decisions

## HED3505 pilot
The HED3505 pilot uses the master case **โรงเรียนอรุณพัฒนา** for course activities, worksheets, dashboards, Forms-linked tasks, and portfolio evidence.

## Submission lifecycle
Assignment published → Student starts from template → Student completes evidence → Pull request / submission record → Automated structural checks → Instructor review → Rubric feedback → Portfolio evidence update.
