# HED3505 Pilot — Known Limitations & Support FAQ

## Known limitations

1. The Interactive Learning Lab is static and does not synchronize learner state across devices.
2. Notes and choices are device/browser-session dependent.
3. Markdown export requires the learner to retain or submit the downloaded artifact.
4. GitHub mobile editing may be less convenient than desktop editing for longer reflections.
5. The Course Hub does not function as an official gradebook.
6. Public repositories are not approved locations for student-specific private work.

## FAQ

### Do students need a login for the Interactive Learning Lab?
No. The current lab itself does not require login.

### Does the lab save answers to a server?
No mandatory backend is used in the approved learner preview.

### Where should student evidence be submitted?
Only to the private destination designated by the instructor.

### Are workflow states grades?
No. NOT_STARTED, IN_PROGRESS, SUBMITTED, REVIEWED, REVISION_REQUESTED, and COMPLETE are workflow states only.

### What if the Markdown file is lost?
Repeat/export the module evidence if possible, or follow the instructor's approved recovery process.

### What if a student accidentally posts private information publicly?
Pause the workflow and notify the instructor. Do not duplicate the exposed information in another public location.
