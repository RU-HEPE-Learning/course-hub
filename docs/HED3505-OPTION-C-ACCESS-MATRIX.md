# HED3505 Option C — Access Matrix

| Resource | Student | Instructor | Public | Notes |
|---|---|---|---|---|
| Course Hub | Read | Read/Edit as authorized | Yes | Learning entry only |
| Interactive Learning Lab | Use | Use/Review source | Yes | No login required |
| Public course materials | Read | Edit as authorized | Yes | No student-specific content |
| Private submission channel | Submit own work | Review assigned work | No | Exact destination to be confirmed |
| Private feedback | View own feedback | Create feedback | No | Not public |
| Revision artifact | Submit own revision | Review | No | Maintain version trail where possible |
| Private portfolio artifact | Access own artifact | Review as authorized | No | Student-specific evidence |
| Official grade record | As institution permits | As institution permits | No | Outside public GitHub |

## Principle

Least privilege, private-by-default, minimum identity exposure.
