# HED3505 Option C — Onboarding Architecture

Status: APPROVED BASELINE / PRE-REAL-STUDENT ACTIVATION

## Architecture

### Public learning layer — GitHub
Use GitHub for:
- Course Hub entry
- HED3505 course materials
- Interactive Learning Lab
- activity instructions
- de-identified templates and examples

### Private learning-record layer — instructor-controlled private channel
Use the approved private channel for:
- student-specific submission
- instructor feedback
- revision evidence
- portfolio artifacts
- identity-linked records where strictly necessary

The exact private platform/destination is intentionally not fabricated here and must be confirmed before real-student start.

## Student journey

Course Hub
→ HED3505
→ Interactive Learning Lab
→ complete module
→ export/copy evidence
→ submit to approved private channel
→ receive feedback privately
→ revise
→ retain portfolio artifact privately

## Boundary

Public GitHub must not contain student IDs, private contact details, personal health information, official grades, identity mappings, or confidential school information.
