# HED3505 Pilot — Teacher Quick Start

Status: PILOT PREPARATION ONLY.

## Purpose

Validate the end-to-end learner workflow before full-cohort activation.

## Teacher sequence

1. Confirm Course Hub → HED3505 → Interactive Learning Lab path.
2. Use a synthetic/de-identified walkthrough first.
3. Confirm assignment, submission, feedback, revision, and portfolio paths.
4. Observe workflow friction; do not score the platform itself as student achievement.
5. Keep official grades outside public repositories.

## Workflow states

NOT_STARTED → IN_PROGRESS → SUBMITTED → REVIEWED → REVISION_REQUESTED → COMPLETE

These are workflow states only, not grades.

## Review focus

- entry clarity;
- mobile usability;
- evidence export;
- private submission;
- feedback visibility;
- revision handling;
- portfolio continuity;
- privacy;
- support burden.

## Stop conditions

Stop the pilot if:
- a student is pushed toward public disclosure of personal/private work;
- a required path is broken;
- identity or grade data would need to be stored publicly;
- a BLOCKER/HIGH defect appears.
