# Student Workflow

For HED3505, use one consistent sequence:

1. Open the HED3505 entry page.
2. Open the current weekly learning package.
3. Open the matching assignment.
4. Review the task, evidence requirements, and rubric.
5. Complete work in the designated private repository or portfolio space.
6. Add only the required evidence and reflection.
7. Submit through the designated repository / pull-request / portfolio workflow.
8. Resolve structural-validation warnings if any.
9. Receive instructor feedback.
10. Revise where requested.
11. Record the final accepted evidence in the portfolio.

Canonical pattern:

**Learn → Do → Save Evidence → Submit → Reflect & Review Feedback**

GitHub Classroom is not required. A command line is not required for the baseline student workflow.
