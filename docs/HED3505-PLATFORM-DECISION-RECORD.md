Status: ACTIVE DECISION RECORD

## 1. Decision Context

The HED3505 controlled pilot requires two separate platform layers:

1. a public learning layer for course entry, instructional materials, and the Interactive Learning Lab; and
2. a private student-work layer for submission, feedback, revision, and portfolio evidence.

The public learning layer has already been implemented using GitHub.

A private destination must still be selected before any real-student pilot begins.

## 2. Decisions Already Approved

### Decision A — Learning architecture

APPROVED:

**Option C**

GitHub is the public learning layer.

The private student-work layer will use an instructor-controlled private platform/channel.

### Decision B — GitHub boundary

GitHub public areas may contain:

- course materials;
- learning instructions;
- approved de-identified examples;
- the HED3505 Interactive Learning Lab;
- workflow documentation.

GitHub public areas must not contain:

- student IDs;
- private contact details;
- personal health information;
- official grades;
- student identity mappings;
- confidential school information.

## 5. Minimum Decision Criteria

The selected private platform must support:

- private-by-default student work;
- controlled instructor access;
- clear student submission destination;
- private feedback return;
- revision handling;
- portfolio artifact retention;
- mobile usability where practical;
- minimum necessary identity exposure;
- straightforward access removal;
- practical rollback;
- low support burden for a 3–5 student pilot.

## 6. Excluded Uses

The selected platform must not be used to justify:

- public student submissions;
- public health information;
- public official grades;
- unnecessary identity collection;
- full-cohort activation before pilot evaluation.

## 7. Decision Authority

The final private-platform selection requires explicit human confirmation.

Examples of valid confirmation:

- APPROVE GOOGLE DRIVE
- APPROVE INSTITUTIONAL LMS
- APPROVE MICROSOFT TEAMS
- APPROVE <named private platform>

Generic approval without a named platform does not resolve this gate.
