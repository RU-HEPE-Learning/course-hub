# HED3505 Pilot — Submission, Feedback & Portfolio Guide

## Submission

1. Complete the relevant Interactive Learning Lab module.
2. Export or copy the module-specific learning evidence.
3. Place evidence only in the instructor-designated private assignment/portfolio space.
4. Mark workflow status as SUBMITTED using the approved mechanism.

## Feedback

Instructor reviews the artifact and either:
- moves it to REVIEWED;
- requests a revision using REVISION_REQUESTED.

Feedback should address evidence quality, reasoning, alignment, and unsupported claims.

## Revision

The learner revises the artifact without deleting the prior learning trail where version history is available.

## Portfolio

Retain the progressive sequence:

WS1 → WS2 → WS3 → WS4 → WS5

Each later artifact should build on prior evidence rather than restart from zero.

## Boundary

Workflow state is not an official grade.
Official grades remain in the institution-approved grading process.
