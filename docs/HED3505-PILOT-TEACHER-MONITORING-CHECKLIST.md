# HED3505 Controlled Pilot — Teacher Monitoring Checklist

## Before each pilot session
- Confirm live lab link works.
- Confirm private submission destination is available.
- Confirm no public identity/grade requirement exists.
- Confirm rollback guide is accessible.

## Observe
- Start-path clarity
- Mobile navigation
- Prompt/reveal usability
- Evidence export
- Submission clarity
- Feedback visibility
- Revision clarity
- Portfolio continuity
- Support requests

## Record only operational observations
Do not record unnecessary personal information.

## Stop immediately if
- student work becomes public unexpectedly;
- privacy boundary fails;
- a HIGH/BLOCKER defect appears;
- submission or feedback path breaks;
- official grades or sensitive identity data would need to be public.
