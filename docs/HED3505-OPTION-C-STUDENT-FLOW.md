# HED3505 Option C — Exact Student Flow

## Step 1 — Enter
Open the HED3505 Course Hub entry.

## Step 2 — Learn
Open the Interactive Learning Lab:
https://kasemch.github.io/hed3505-interactive-lab/

## Step 3 — Interact
Complete the assigned module using:
Prompt → Tap → Reveal → Discuss → Decide → Save

## Step 4 — Export evidence
Copy or download the module-specific evidence.

## Step 5 — Submit privately
Upload/paste evidence only into the instructor-confirmed private submission destination.

## Step 6 — Check feedback
Return to the same private channel to read instructor feedback.

## Step 7 — Revise
Update the artifact in the private channel according to feedback.

## Step 8 — Retain portfolio evidence
Keep the accepted WS artifact in the approved private portfolio location.

## If the private destination is unclear

Do not submit publicly.
Stop and ask the instructor for the confirmed private destination.
