# HED3505 Option C — Teacher Flow

## Before pilot start
- Confirm the public Course Hub route.
- Confirm the live Interactive Learning Lab.
- Confirm the exact private submission destination.
- Confirm who can access each student artifact.
- Confirm feedback and revision path.
- Confirm rollback procedure.

## During pilot
1. Direct learners to the public learning layer.
2. Receive student-specific work only through the confirmed private channel.
3. Review evidence quality and reasoning.
4. Return feedback privately.
5. Use workflow states only for process tracking:
   NOT_STARTED → IN_PROGRESS → SUBMITTED → REVIEWED → REVISION_REQUESTED → COMPLETE
6. Keep official grades in the institution-approved grading process.

## Stop conditions
Pause if private work becomes public, access is ambiguous, feedback cannot be returned privately, or a HIGH/BLOCKER defect appears.
