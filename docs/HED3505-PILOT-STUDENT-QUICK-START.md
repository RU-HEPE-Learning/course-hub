# HED3505 Pilot — Student Quick Start

Status: PILOT PREPARATION ONLY — do not treat as a full-cohort launch.

## Start here

1. Open the HED3505 course entry in the Course Hub.
2. Open the Interactive Learning Lab:
   https://kasemch.github.io/hed3505-interactive-lab/
3. Work through the current module using:
   **Prompt → Tap → Reveal → Discuss → Decide → Save**
4. Save only learning evidence and reasoning.
5. Use the matching assignment/portfolio location designated by the instructor.

## Five-module path

- M1 Problem → Indicator → WS1 Assessment Planning
- M2 Indicator → Instrument → WS2 Instrument Blueprint
- M3 Content Validity → IOC → Reliability → Revision → WS3 Instrument Quality Record
- M4 Data → Interpretation → Decision → WS4 Interpretation & Decision Matrix
- M5 Integrated Evidence → Evaluation Plan → WS5 Integrated Evaluation Plan

## Privacy

Do not enter or publish:
- student ID;
- phone/email unless explicitly required in a private approved space;
- personal health information;
- official grades;
- confidential school information.

The Interactive Learning Lab itself does not require login and does not collect identity or grades.

## If something does not work

Stop the workflow and tell the instructor which step failed. Do not create a public workaround or publish private information.
