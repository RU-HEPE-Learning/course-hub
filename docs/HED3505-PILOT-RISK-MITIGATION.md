# HED3505 Pilot — Risk Mitigation Matrix

| Risk | Impact | Mitigation | Pilot Gate |
|---|---|---|---|
| Confusion between lab and assignment | Evidence may not reach submission path | Student Quick Start clearly separates Learn/Interact from Submit | Must be clear |
| Public/private repo confusion | Privacy exposure | Private-by-default rule and explicit privacy notice | BLOCK if unresolved |
| Accidental PII entry | Privacy risk | No PII requested by lab; warning in student guide | BLOCK if required by workflow |
| GitHub mistaken for official gradebook | Governance error | State explicitly that workflow states are not grades | Must be visible |
| Mobile editing friction | Participation burden | Lab is mobile-first; longer work may use approved alternate private workflow | Monitor |
| Lost Markdown export | Evidence loss | Copy/download guidance and repeatable export | Acceptable with mitigation |
| Feedback location unclear | Revision failure | Feedback guide and teacher workflow define review path | Must be defined |
| Link/deployment failure | Entry failure | Rollback guide and last-known-good release | BLOCK if active |

## Decision rule

No unresolved BLOCKER/HIGH risk may remain before controlled real-student activation.
