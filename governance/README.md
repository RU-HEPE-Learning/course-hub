# Governance

RU-HEPE Learning Hub separates public course information from controlled student work.

## Baseline rules

- Public hub: course descriptions, assignment specifications, rubrics, templates, and non-sensitive examples.
- Controlled repositories: student/group work, drafts, feedback, and assessment evidence where access should be limited.
- Instructor judgment remains authoritative for academic assessment.
- Repository automation must not create or infer academic results without explicit assessment rules and human review.
- Personal, health, or other sensitive data must not be committed to the public hub.

## Change control

Substantive course or assessment changes should identify the evidence/source and be reviewed through a pull request or documented issue where practical.
